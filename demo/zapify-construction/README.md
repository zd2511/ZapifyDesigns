# Zap Construct website

A responsive, single-page construction and civil engineering website inspired by the supplied reference image.

## Files
- `index.html` — page structure and content
- `styles.css` — layout, colors, typography, responsive behavior
- `script.js` — mobile navigation and current year

## Run
Open `index.html` in a browser. The font and hero photograph are loaded from external URLs, so an internet connection is needed for those assets.

## Before publishing
Replace the sample phone number, email address, services, and any other placeholder business details with verified company information. For production, download and host the hero photograph locally with appropriate usage rights.
