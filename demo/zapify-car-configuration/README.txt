CAR. — INTERACTIVE CONCEPT WEBSITE

Open index.html in a modern browser. No build step or server is required.

Included interactions:
- Responsive desktop/tablet/mobile layout
- Feature category tabs that update vehicle callouts
- Clickable car hotspots with feature descriptions
- Paint swatches and configurable paint selection
- Feature-card horizontal carousel
- Favourite toggle, search, navigation menu, accessory notification
- Configure modal with equipment package and saved selection toast

The coupe image is included locally in assets/. Google Fonts and the optional passenger-seat photo require an internet connection; the rest of the site runs locally.

This is a visual concept recreation. Vehicle branding/specifications are illustrative and are not an official Mercedes-Benz configurator.
