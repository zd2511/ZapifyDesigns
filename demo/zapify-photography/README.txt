ZAPIFY PHOTOGRAPHY — WEBSITE FILES

Files:
- index.html: page structure and content
- styles.css: responsive styling and visual design
- script.js: mobile navigation and email-based contact form

HOW TO PREVIEW
Open index.html in a browser. Internet access is needed for the Google Fonts and Unsplash photography used as remote image URLs.

BEFORE PUBLISHING
1. Replace +27 00 000 0000 in index.html with the business phone number.
2. Replace hello@zapify.co.za in script.js with the correct contact email.
3. Replace the sample photography images with your licensed/owned images if desired.
4. Upload all three website files to the same hosting directory.

The contact form uses a mailto link and does not store submissions or send them through a server.
