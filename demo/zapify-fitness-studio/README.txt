ZAPIFY FITNESS WEBSITE
=======================

Files
- index.html: website structure and content
- styles.css: responsive dark fitness design
- script.js: mobile navigation and footer year

How to preview
1. Extract the ZIP.
2. Open index.html in a browser.
3. The website uses Google Fonts and Unsplash-hosted photos, so an internet connection is needed for those assets.

Customise
- Replace the phone number and email in index.html with the correct business contact details.
- Update the location in the top bar if needed.
- Photos are configured in styles.css as Unsplash URLs.
