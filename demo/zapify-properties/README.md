# Zapify Properties

A responsive, dark luxury real-estate landing page inspired by the supplied reference image. Branding and prices have been localized for South Africa (ZAR / R).

## Files
- `index.html` — page structure and sample property cards
- `styles.css` — responsive design, layout, colours, mobile navigation
- `script.js` — mobile menu, favourite buttons, property filtering and consultation modal

## Run locally
Open `index.html` in a modern browser. Internet access is required for the Google Fonts and Unsplash property photography.

## Before publishing
Replace the sample listing details, contact email, and photography with approved client content. Connect the search form and consultation CTA to a real property database/CRM if live listings are required. This is a front-end demo and does not include a backend.
