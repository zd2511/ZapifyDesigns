# Zapify Designs website

A responsive, multi-page static website concept for Zapify Designs, using the Blush & Mocha palette and an elegant script wordmark.

## Pages
- Home (`index.html`)
- About Us (`about.html`)
- Services (`services.html`)
- Portfolio (`portfolio.html`)
- Contact Us (`contact.html`)
- Blog (`blog.html`)
- Agency Partner (`agency-partner.html`)

## Run locally
Open `index.html` in a browser, or use a local static server (for example, VS Code Live Server). No build step is required.

## Deploy
Upload the contents of this folder to any static hosting provider, or publish the folder using GitHub Pages. Keep the file structure intact so the relative asset paths continue to work.

## Important details to review before publishing
- Contact details are set to `info@zapifydesigns.co.za` and WhatsApp `074 389 9657` (WhatsApp link uses international format internally).
- Portfolio links point to `https://amani-interiors.co.za/` and `https://vtsenergysecurity.co.za/`. Portfolio preview images are loaded from an external screenshot service and attempt to show the live websites; their availability depends on that service being able to access each site.
- The website communicates services from R350 as a starting point, not a fixed price for every service. Custom quotations are required for scope-dependent work.
- Optional hosting is described as R125/month including website maintenance, subject to terms; confirm and publish the full terms before taking orders.
- The contact form prepares an enquiry in WhatsApp; it does not store or transmit form submissions to a server.
- Blog articles are starter content and should be reviewed, expanded and updated over time.
- Google Fonts are loaded online; system fallback fonts are included.

## Design notes
The site includes mobile navigation, responsive layouts, scroll reveal animations with reduced-motion support, portfolio filters, blog search/category filters, a back-to-top button, and WhatsApp-based contact form handling.


Graphic design pricing is shown as starting from R30. The blog page is intentionally marked Coming Soon and invites PC troubleshooting submissions by email or WhatsApp.


## Portfolio demo websites
The `demo/` directory contains the interactive demo websites imported from the previous Zapify Designs website. Open the Portfolio page and select “Demo concepts” to browse them. Each card has an embedded preview and an “Open full demo” link. Keep the `demo/` directory alongside the main HTML pages when deploying.
